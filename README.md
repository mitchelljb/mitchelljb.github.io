## Mitchell Bakker

Personal website of Mitchell Bakker, Solution Specialist Microsoft Teams & Copilot.

**[mitchellbakker.nl](https://mitchellbakker.nl/)**

### Built with
- Plain HTML, CSS and JavaScript, no build step or framework
- Self-hosted fonts: [Inter](https://rsms.me/inter/) and [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans) (SIL Open Font License 1.1)
- Icons by [Font Awesome Free](https://fontawesome.com/) 5.15.3
- Hosted on GitHub Pages behind Cloudflare

### Languages
The site is available in English (`index.html`) and Dutch (`nl/index.html`). Both pages share the same CSS and JavaScript; keep their content in sync when making changes.

### Caching
Cloudflare and browsers cache CSS and JavaScript for up to 10 minutes. The pages load them with a version (`main.css?v=…`, `main.js?v=…`, `404.js?v=…`); change that version in `index.html`, `nl/index.html` and `404.html` whenever you edit a CSS or JS file, so visitors get the new file straight away.
